# Programming with Python

A collection of Python scripts and exercises covering fundamental programming concepts — from basic syntax to object-oriented programming.

## Overview

This repository serves as a learning resource for Python programming. It includes standalone scripts demonstrating core language features as well as organized topic folders for deeper exploration.

## Repository Structure

### Directories

| Directory | Description |
|-----------|-------------|
| `Object_Oriented_Programming/` | Examples and exercises on OOP concepts in Python |
| `Python_Lists/` | Working with Python lists |
| `Python_Sets/` | Working with Python sets |

### Scripts

| File | Description |
|------|-------------|
| `hello_world.py` | Classic introductory "Hello, World!" program |
| `print_function.py` | Using Python's `print()` function |
| `indents.py` | Understanding Python indentation |
| `addnumbersfunction.py` | Function to add numbers |
| `addnumbersfunctions.py` | Additional number-adding functions |
| `lists.py` | Working with Python lists |
| `mem.py` | Memory-related concepts |
| `my_first.py` | First Python program |
| `sr.py` | Script exercise |
| `sr1.py` | Script exercise (continued) |

## Getting Started

### Prerequisites

- Python 3.x

### Running a Script

```bash
python hello_world.py
```

## Topics Covered

- **Basic Syntax** — print statements, indentation, variables
- **Functions** — defining and calling functions
- **Data Structures** — lists, sets
- **Object-Oriented Programming** — classes, objects, and OOP principles
